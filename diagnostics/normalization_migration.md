# Solver restoration and normalization validation

Validated on 2026-11-14 on `main`. The `ravat-etal-testing` branch remains separate and unchanged.

## Method mapping

| Public method | Implementation and provenance |
|---|---|
| `spectral` | Original unnormalized dense least-squares fit, restored exactly from `9b7e7ef` (the parent of the Schmidt conversion commit `45423d1`). |
| `gauss_legendre`, normalization **1** | Original nested volume quadrature from `398edc8`, with its numerical calculation unchanged. This remains the default. No harmonic basis is used. |
| `gauss_legendre`, normalization **2** | Recent Schmidt semi-normalized implementation from `398edc8`, moved from the spectral program into `gravmag_sphere_normalized.f90`. Retains native Fourier transforms, extended-range recurrences, automatic parameter selection, regularization, fixed gravity mass term, collective bodies, edge corrections, hybrid mode, diagnostics and memory preflight. |
| `gauss_legendre`, normalization **3** | Extension of the same implementation to geodetic fully normalized (4pi) harmonics. Analysis, vector norms, filtering, point evaluation and correction synthesis all use the selected normalization. |

Normalized options exclude the Condon–Shortley phase. The restored spectral method retains its original phase-bearing unnormalized recurrence. Both normalized options support magnetic and gravity inputs; the selection is explicit.

The real geodetic fully normalized basis is `F_lm = sqrt(2*l+1) * S_lm`, with `S_lm` the Schmidt semi-normalized basis. Projection norms scale by `2*l+1`; coefficients scale inversely. The definitions follow [SHTOOLS normalization conventions](https://shtools.github.io/SHTOOLS/fortran-real-spherical-harmonics.html). These option numbers are specific to GravMagSphere and do not correspond to SHTOOLS's numerical selectors.

## Preserved evidence

The original numerical data under `native_high_degree/` and `gauss_legendre_comparison/` are retained. Their historical `spectral` labels refer to the recent Schmidt algorithm, now option **2**. Their source hashes still identify the original evaluated implementation. The historical degree-10,000 results are not new measurements of the restored dense method or fully normalized option **3**.

`tests/fixtures/solver_method_baselines.json` contains ten field baselines generated by separately compiling the historical commits, including the commit IDs, compiler flags and source hashes. Tests compare the current public entry points against these fixed fields for magnetic and gravity cases with multiple bodies:

- Original dense spectral calculation.
- Original Gauss–Legendre volume quadrature.
- Recent pure Schmidt calculation with damping.
- Recent Schmidt automatic selection and local edge corrections.
- Recent Schmidt hybrid evaluation.

## Current verification

All **74 tests passed**, including the existing quadrature, geometry, units, convergence, mass-term, native recurrence, Fourier, independent SciPy SVD and output-path checks. The existing Schmidt public-entry-point tests now select option **2**. The full-suite run used the original checkout's ignored Reiner Gamma example fixtures, which are not tracked in Git.

New tests in `tests/test_normalization.py` check historical field agreement, normalization names and invalid controls, collective output dimensions, normalized coefficient roundtrips through degree 128, and fully normalized vector synthesis against SciPy and arbitrary-precision Jacobi references through degree 2800, including polar and seed-underflow cases. Fully normalized damped, local-corrected and hybrid fields also agree with the historical Schmidt fields within the test tolerances.

Fresh degree-600 checks for options **2 and 3** are saved in [normalization_validation.json](normalization_validation.json). Both full-bandwidth coefficient projections pass; relative analytical magnetic and gravity source-field errors are below `1.1e-12`. These are point-source consistency checks using a deliberately single-cell source mesh, not an accuracy claim for finite-body discretization or near-surface truncated harmonic fields.

Rerun the degree-600 checks with:

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONPATH=src python diagnostics/normalization_validation.py
```

The shell build also passes in an isolated output folder. The updated comparison script completed 126 runs across six magnetic/gravity, block/polygon and surface/orbital/far-field cases, with all six reference-resolution checks converged. It includes the restored spectral method and both normalized Gauss–Legendre options as separate series. Schmidt and fully normalized convergence agrees across all tested cases and degrees. Rerunning it with an explicit output directory preserves the historical report:

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MPLBACKEND=Agg PYTHONPATH=src \
  python diagnostics/gauss_legendre_compare.py /tmp/gravmag-normalization-comparison
```

For a fresh option-2 high-degree sweep without overwriting historical results, set `GRAVMAG_NATIVE_DESTINATION` before running `diagnostics/native_high_degree.py`.
